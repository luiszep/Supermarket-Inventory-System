# Multi-Branch Supermarket Inventory & Reporting System

Team database-systems project for managing inventory and reporting across multiple supermarket branches.

## Overview

Built as a four-person UTEP database project, this system models the core operational data for a multi-branch supermarket: branches, staff, suppliers, and inventory items. The emphasis was on clean relational design, normalized tables, and SQL-driven reporting rather than a polished end-user application.

## What it demonstrates

- Normalized MySQL schema design from an ER/relational model
- CRUD workflows for core inventory entities
- Dynamic SQL reporting using `JOIN`, `GROUP BY`, aggregate functions such as `SUM`, and ordered result sets
- Branch-level inventory visibility and supplier/staff relationships
- Team-based database design, implementation, and presentation

## Repository contents

- `Database_Presentation.pdf` — final project presentation.
- `team4DB/` and contributor folders — team implementation files and individual components.
- `index.html` / `helloworld.php` — lightweight web/demo entry points included with the project materials.

## Tech stack

MySQL · SQL · PHP · HTML
